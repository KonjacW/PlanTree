# PlanTree 工作流

当用户希望管理任务树或查看任务树计划状态时，使用 PlanTree MCP 工具。

## 工具顺序

1. 首次进入或需要恢复演示状态时，调用 `create_or_load_demo` 获取服务端快照。
2. 需要查看图形化小窗时，调用唯一的渲染工具 `render_plan_tree`，并传入最新快照。
3. 用户提出添加、改写、展开或裁剪节点时，调用 `edit_node`；不要在对话中自行修改计划状态。
4. 用户要求推进可执行任务时，调用 `simulate_execution`。
5. 用户要求撤回最近一次成功编辑时，调用 `undo_last_edit`。
6. 用户明确确认重置后，调用 `reset_demo`。

## 响应约束

- 以 MCP 工具返回的最新结构化快照为准。
- UI 不可用时，继续基于数据工具的结构化结果说明树、有效性、影响范围和审计记录。
- 第一阶段只使用确定性模拟规则；不得将其描述为真实 LLM 规划、SWE-bench 执行或代码执行。
