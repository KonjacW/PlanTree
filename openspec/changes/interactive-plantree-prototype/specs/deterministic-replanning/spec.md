## ADDED Requirements

### Requirement: 确定性模拟规划器
系统 MUST 使用不调用外部模型、网络服务或代码执行器的模拟规划器。对于相同的计划快照、编辑操作和演示配置，规划器 MUST 产生相同的子节点、依赖关系、状态转换和重规划摘要。

#### Scenario: 重复执行相同展开操作
- **WHEN** 系统以相同初始计划和演示配置两次展开同一节点
- **THEN** 两次得到的节点标题、顺序、类型和依赖关系完全一致

### Requirement: 局部影响范围计算
编辑成功后，系统 MUST 将被编辑节点、其未裁剪后代以及直接或传递依赖该节点输出的未完成节点纳入影响范围。根节点不在影响范围内时，所有不属于该集合的分支 MUST 保持其 ID、字段、状态、子节点顺序和版本不变。

#### Scenario: 改写调查节点
- **WHEN** 用户改写调查分支中的一个节点，且测试分支显式依赖该节点输出
- **THEN** 系统将被改写节点、其后代和测试分支列入影响范围，同时保留无依赖的文档分支不变

### Requirement: 编辑后的局部重规划
系统 MUST 在有效编辑后仅重规划影响范围内的未裁剪节点。改写操作 MUST 替换受影响节点的模拟子树；展开操作 MUST 根据节点类型生成预定义的子任务模板；添加操作 MUST 将用户提供的节点纳入局部排序；裁剪操作 MUST 移除该分支的后续规划。

#### Scenario: 展开修复阶段
- **WHEN** 用户展开处于待规划状态的修复阶段
- **THEN** 系统在该阶段下生成确定性的定位代码、实施修复和代码审查子任务，并更新该阶段版本

### Requirement: 依赖一致性同步
局部重规划完成后，系统 MUST 移除指向已裁剪节点的依赖、保留仍然有效的依赖，并把无法满足的依赖标记为失效。任何仍在主树中的待执行或执行中节点 MUST 不依赖于不存在、已跳过或失效的输出。

#### Scenario: 裁剪被测试节点依赖的分支
- **WHEN** 用户裁剪测试节点唯一依赖的修复分支
- **THEN** 系统将测试节点标记为失效，记录未满足依赖，并阻止其进入执行中状态
