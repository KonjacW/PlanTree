## ADDED Requirements

### Requirement: 持久任务树表示
系统 MUST 以单一根节点表示一个计划，并为每个节点保存稳定 ID、标题、目标说明、节点类型、父节点 ID、子节点顺序、显式依赖、状态、版本号和创建来源。节点类型 MUST 至少区分目标、阶段、可执行叶节点与检查点；节点状态 MUST 至少区分待规划、待执行、执行中、已完成、已跳过与失效。

#### Scenario: 加载预置任务树
- **WHEN** 用户打开原型
- **THEN** 系统显示一个包含软件缺陷修复目标、调查、修复、测试和验证分支的有效初始任务树

### Requirement: 树状浏览与节点选择
MCP App 小窗 MUST 以保留层级、顺序、状态和依赖提示的树状视图展示当前计划。用户 MUST 能选择任一未裁剪节点，并在详情面板查看其全部可编辑字段、直接子节点、直接依赖和当前版本。

#### Scenario: 查看叶节点详情
- **WHEN** 用户选择一个可执行叶节点
- **THEN** 详情面板显示该节点的目标、状态、依赖、版本和最近一次相关审计记录

### Requirement: 结构化编辑操作
系统 MUST 支持添加子节点、改写节点目标、展开节点和裁剪节点或子树。系统 MUST 拒绝对根节点的裁剪、向可执行叶节点添加子节点、以及会产生循环依赖的编辑；被拒绝的编辑 MUST 不改变计划版本。

#### Scenario: 添加子节点
- **WHEN** 用户为阶段节点提交有效的新子任务标题和目标
- **THEN** 系统将新节点添加到该阶段末尾，并记录一次添加操作

#### Scenario: 改写节点目标
- **WHEN** 用户保存一个非空的目标改写
- **THEN** 系统保存新目标、标记该节点需要重规划，并启动局部重规划流程

#### Scenario: 裁剪子树
- **WHEN** 用户确认裁剪一个非根节点
- **THEN** 系统将该节点及其后代标记为已跳过，并从主树视图中移除该分支

### Requirement: 撤销最近一次可逆编辑
系统 MUST 允许用户撤销最近一次成功的添加、改写、展开或裁剪操作。撤销 MUST 恢复该操作前的树结构、节点字段、状态、依赖和计划版本，并产生新的审计记录；系统 MUST 不支持跨会话撤销。

#### Scenario: 撤销裁剪
- **WHEN** 用户在裁剪子树后选择撤销
- **THEN** 系统恢复被裁剪节点及其后代，并恢复裁剪前的计划有效性结果
