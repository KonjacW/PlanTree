## Why

PlanTree 的研究主张依赖于一个可见、可编辑且可重新规划的任务树，但现有项目资料尚未把该主张收敛为可演示、可验证且可最终交付为 Codex 插件的交互原型。第一阶段需要建立一个不依赖真实 LLM 或 SWE-bench 运行环境的确定性闭环，以验证用户结构化编辑是否能触发范围正确、可审计的局部重规划。

## What Changes

- 建立可安装的 Codex 本地插件原型；插件以 MCP 服务器管理任务树状态，并在 Codex 会话内以 MCP App Picture-in-Picture 小窗展示交互界面，不打开独立浏览器。
- 支持选中节点、查看详情、添加子节点、改写节点目标、展开可分解节点、裁剪节点或子树，以及撤销最近一次编辑。
- 引入确定性的模拟规划器；它依据节点类型和编辑操作生成可预测的子树、依赖关系与计划版本，而不调用真实 LLM、外部工具或代码执行沙盒。
- 每次编辑后计算受影响范围：保留未受影响分支，仅更新被编辑节点、其后代及显式依赖于该节点输出的节点。
- 提供计划有效性检查、执行状态的模拟展示与不可变审计日志；MCP 工具在小窗不可用时仍可返回结构化结果，使 Codex 可继续完成工作流。
- 预置一个软件缺陷修复演示任务，保持后续与 SWE-bench 实验场景的一致性；本变更不实现真实基准执行或三组实验。

## Capabilities

### New Capabilities

- `task-tree-authoring`: 创建、展示、选择和结构化编辑持久任务树。
- `deterministic-replanning`: 使用模拟规划器按影响范围进行可预测的局部重规划并维护依赖一致性。
- `plan-validation-and-audit`: 验证计划有效性、模拟节点执行状态，并记录可追溯的操作和重规划日志。
- `prototype-demo-workflow`: 提供可安装的 Codex 插件、MCP 工具与内嵌小窗形式的缺陷修复演示工作流。

### Modified Capabilities

无。

## Impact

新增独立的 Codex 插件包、任务树领域模型、MCP 工具服务、MCP App 小窗组件、规划器适配边界与自动化测试。原型不依赖模型服务、SWE-bench、GitHub、容器运行时或真实代码执行器；后续实验层和真实 LLM 适配将作为独立变更接入稳定的 MCP 与领域接口。
