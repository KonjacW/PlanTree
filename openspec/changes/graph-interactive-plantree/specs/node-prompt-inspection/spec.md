## ADDED Requirements

### Requirement: 单节点提示词详情
系统 MUST 为单个选中节点生成可阅读、可复制的本地规划提示词。自动提示词 MUST 包含节点标题、目标、类型、状态、父节点上下文、直接子节点、直接依赖和保持任务树一致性的操作说明，并 MUST 由当前快照纯函数派生。自动提示词与人工提示词 MUST NOT 发送到外部网络服务。

#### Scenario: 查看阶段节点提示词
- **WHEN** 用户选中一个阶段节点并请求查看提示词
- **THEN** 系统显示该节点当前的派生提示词，内容包含其目标、父节点、子节点和依赖信息

### Requirement: 提示词面板生命周期
系统 MUST 允许用户通过可点击入口或 `P` 键开关单节点提示词面板。多选状态下系统 MUST 不展示批量提示词；如果当前展示提示词的节点在服务端更新后不再存在，系统 MUST 自动关闭面板。

#### Scenario: 任务树更新移除当前节点
- **WHEN** 提示词面板打开且服务端返回的最新快照不含当前节点
- **THEN** 系统关闭提示词面板并将选择恢复到根节点或清空选择

### Requirement: 人工提示词持久化覆盖
系统 MUST 允许用户编辑单个节点的完整提示词并将非空人工文本保存为该节点的 `customPrompt`。保存操作 MUST 同时记录 `customPromptBaseVersion`，MUST 增加节点与计划版本、写入审计并进入撤销历史。没有人工覆盖时系统 MUST 显示自动派生提示词；存在人工覆盖时系统 MUST 默认显示人工文本。人工提示词 MUST 通过共享服务端快照在本地 Web 与 MCP PiP 间保持一致。

#### Scenario: 保存人工提示词
- **WHEN** 用户编辑节点提示词并保存非空文本
- **THEN** 系统以当前 `expectedVersion` 保存人工文本，并在服务端返回的新快照中显示相同人工提示词

### Requirement: 编辑保护与恢复自动生成
系统 MUST 在提示词面板提供编辑、保存、取消和恢复自动生成入口。首次编辑尚无人工覆盖的节点时，编辑器 MUST 以当前自动派生提示词作为初始文本；已有覆盖时 MUST 以人工文本作为初始文本。系统 MUST 拒绝保存空白文本。存在未保存修改时，关闭面板、切换节点或按下 `Esc` MUST 先确认是否放弃修改。恢复自动生成 MUST 清除 `customPrompt` 与 `customPromptBaseVersion`，并重新显示当前快照派生提示词。

#### Scenario: 放弃未保存提示词修改
- **WHEN** 用户修改提示词但尚未保存并请求关闭面板
- **THEN** 系统显示放弃修改确认，且在用户确认前保留编辑内容和提示词面板

### Requirement: 人工提示词过期提示
当节点版本高于 `customPromptBaseVersion` 时，系统 MUST 显示“人工提示词可能已过期”。该提示 MUST NOT 自动修改、合并或覆盖人工提示词；用户 MUST 能继续编辑人工文本或恢复自动生成。

#### Scenario: 节点变化后保留人工提示词
- **WHEN** 已保存人工提示词的节点后来因其他计划操作产生更高节点版本
- **THEN** 系统继续显示原人工文本并标记其可能已过期
