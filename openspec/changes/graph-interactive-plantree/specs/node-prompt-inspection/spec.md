## ADDED Requirements

### Requirement: 单节点内容详情
系统 MUST 为单个选中节点展示可阅读、可复制的执行内容。展示文本 MUST 仅由节点的任务、可选方法和可选验收纯函数派生，MUST NOT 重复显示节点 ID、类型、状态、父子关系或前置依赖。没有显式验收时，系统 MUST 显示 Agent 自评要求。

#### Scenario: 查看阶段节点内容
- **WHEN** 用户选中一个阶段节点并请求查看节点内容
- **THEN** 系统只显示该节点的任务、已有方法和已有验收，不显示图结构元数据

### Requirement: 节点内容面板生命周期
系统 MUST 允许用户通过可点击入口或 `P` 键在主窗口内开关单节点内容面板。节点内容、执行链与快捷键帮助 MUST 互斥复用同一内联工作区，且 MUST NOT 为这些只读或编辑界面创建遮罩。多选状态下系统 MUST 不展示批量内容；如果当前节点在服务端更新后不再存在，系统 MUST 自动关闭面板。

#### Scenario: 任务树更新移除当前节点
- **WHEN** 节点内容面板打开且服务端返回的最新快照不含当前节点
- **THEN** 系统关闭节点内容面板并清理该节点的本地草稿

### Requirement: 结构化节点内容编辑
系统 MUST 允许用户编辑节点表示的任务、方法和验收，而不是编辑一段自由文本提示词。保存 MUST 复用 `edit_node rewrite`、携带当前 `expectedVersion`，并以服务端返回快照刷新任务图与派生执行文本。关系、依赖、状态和节点 ID MUST NOT 出现在内容编辑器中。

#### Scenario: 保存任务、方法和验收
- **WHEN** 用户修改任务，填写一种方法并增加测试验收后保存
- **THEN** 系统调用 `edit_node rewrite` 保存对应结构化字段，并从新快照重新生成节点卡片与执行文本

#### Scenario: 清除可选内容
- **WHEN** 用户清空方法并删除所有显式验收后保存
- **THEN** 系统以 `method: null` 和空 `acceptance` 清除这些字段，执行文本改为要求 Agent 自评

### Requirement: 编辑保护
系统 MUST 拒绝保存空白任务或空白验收要求。存在未保存修改时，关闭面板、切换节点、触发其他写操作或按下 `Esc` MUST 先确认是否放弃修改。

#### Scenario: 放弃未保存节点修改
- **WHEN** 用户修改节点内容但尚未保存并请求关闭面板
- **THEN** 系统显示放弃修改确认，且在用户确认前保留结构化草稿和节点内容面板

### Requirement: 执行文本以结构化节点为唯一来源
系统 MUST 只根据节点的任务、方法和验收生成执行链中的 `task.prompt`。遗留 `customPrompt` 与 `customPromptBaseVersion` MUST NOT 覆盖节点内容；结构化改写 MUST 清除这两个遗留字段。

#### Scenario: 旧快照含人工提示词
- **WHEN** 导入的节点同时含结构化内容和遗留 `customPrompt`
- **THEN** 节点面板与执行链均使用结构化内容，后续 rewrite 清除遗留字段
